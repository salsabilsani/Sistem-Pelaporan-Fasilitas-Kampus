SiLapor – Sistem Informasi Pelaporan Fasilitas Kampus

SiLapor merupakan aplikasi mobile berbasis Flutter yang dikembangkan untuk memudahkan mahasiswa dan civitas akademika dalam melaporkan kerusakan fasilitas kampus, seperti AC, proyektor, meja, kursi, lampu, dan fasilitas lainnya agar dapat ditindaklanjuti oleh pihak pengelola kampus.
